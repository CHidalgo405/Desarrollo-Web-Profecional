Menú Hamburguesa

La solución estándar para pantallas pequeñas. Oculta la navegación detrás de un icono para maximizar el área de contenido.

Principios UX

  • Visibilidad: El usuario siempre debe saber dónde está (Breadcrumbs) y a dónde puede ir.
  • Consistencia: El menú no debe cambiar de lugar ni de orden entre páginas.
  • Feedback: Los enlaces activos deben brillar o cambiar de color para indicar la ubicación actual.
